# GPU 钱包靓号生成器（USDT / TRON 波场）

基于 GPU 加速的 USDT（TRON 波场）钱包靓号（Vanity Address）批量生成工具，
支持自定义尾数、连号、AA 号、顺子号与自定义地址，可跑 5 / 6 / 7 / 8 / 9 / 10A 连号。

## ✨ 功能特性

- **GPU 加速**：高性能批量生成，RTX 2060 实测约 135 MH/s（≈ 1.35 亿地址 / 秒）
- **自定义尾数**：支持 5 / 6 / 7 / 8 / 9 / 10A 连号
- **AA 靓号**：支持生成 AA 靓号地址（6 / 7 / 8 / 9 / 10A）
- **高仿地址**：支持生成高仿地址
- **顺子地址**：支持生成顺子地址
- **自定义地址**：指定生成任意自定义地址
  - 在 `address.txt` 中写入 20 位数字（前 10 位 + 后 10 位自定义）
  - 修改 `高仿地址.bat` 中的参数 `qian` / `hou`，分别指定保留前面 / 后面几位
  - --quit 1 代表生成几个填写1就生成1个 填写0为无限生成，也可以填写你想生成的靓号地址数量
- **自动分类**：筛选结果自动按数字 / 字母分类
- **顺子筛选**：自动筛选顺子靓号（筛选级别 = 少连号 1 位，如跑 8 连号时 7 位以上顺子会被筛出）

### 2026-09-18
- **全新地址生成算法**：底层基于 secp256k1 椭圆曲线，采用密码学安全随机数生成器（CSPRNG）驱动私钥生成，配合 GPU 并行加速搜索

- **无需多签权限**：私钥为 256 位强随机密钥、全程本地离线生成、无法被暴力破解，无需再依赖 Tron 多签兜底；只有你本人能动用资产，开箱即用、省心放心

## ⚠️ 常见问题

**1. 运行闪退？**
- 确认是否为笔记本混合显卡，请禁用集成显卡（核显）。
- 禁用核显方法：<https://jingyan.baidu.com/article/642c9d34f6b2ae254a46f7e6.html>
**2. 提示 `vc.dll` 错误（请安装VC++运行库）？**

**3. 提示 `OPENCL.dll` 错误（通常服务器出现）？**
- 请安装显卡驱动。GPU 服务器推荐系统：Windows 2019（任何 Windows 版本均可）。
- 下载安装对应显卡驱动：<https://www.nvidia.cn/Download/index.aspx>
- 举例（腾讯云 V100 显卡）搜索下载时选择：
  - Product Type：Data Center / Tesla
  - Product Series：A-Series
  - Product：NVIDIA A100
  - Operating System：你的 Windows 版本（如 Windows Server 2019）
